# RG Asesorías y Seguros — Sitio web

- `index.html`: sitio público (generado con `nueva-web/herramientas/construir_github.py`).
- `admin/`: panel del equipo (solicitudes, conversaciones, clientes, actividad, estadísticas y equipo).
- `caso/`: página privada donde cada cliente sigue su solicitud y conversa con su asesor.
- `config.js`: conexión pública con Supabase (URL y clave publishable).
- `supabase/`: base de datos, Edge Functions (RG AI y correos) e **instrucciones de puesta en marcha** → `supabase/INSTRUCCIONES.md`.
